
# Gaming PC Store

This is a simple gaming PC store website created for my CSCI 3330 Exam 2 project.

## Features

- Customer registration
- View gaming PCs and their specifications
- Add, update, and remove products from the cart
- Checkout and view order history
- Write and view product reviews

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- EJS

## How to Run

1. Install Node.js.
2. Open the project folder in a terminal.
3. Run `npm install`.
4. Run `node server.js`.
5. Open `http://localhost:3000` in a browser.

## Notes

This project uses in-memory data instead of a database. Customer accounts, carts, orders, and reviews are reset when the server restarts.
